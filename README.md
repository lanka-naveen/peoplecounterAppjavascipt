# People Counter Web App

A simple, interactive web application designed to track and count incoming people in real time. Built with core web development fundamentals, this project features dynamic DOM manipulation to increment and log counts seamlessly.

 🚀 Features
Interactive Counter: Click the INCREMENT button to increase the people count dynamically on the screen[cite: 9, 10].
  Save Functionality: Click the SAVE button to log and output the current counter values[cite: 10, 11].
  Clean UI & Responsive Layout: Custom HTML structure styled with clean CSS for visual clarity[cite: 5, 6].

🛠️ Tech Stack
HTML5 – Markup structure for buttons and dynamic display elements[cite: 5].
CSS3 – Styling for layout, button states, and visual contrast[cite: 6].
JavaScript (ES6) – Core application logic, event handlers, and DOM manipulation[cite: 10, 11].
